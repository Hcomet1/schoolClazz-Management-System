# 校园班级管理系统

## 1. 项目概述
面向中小学的班级信息化管理平台，核心服务于学校领导、班主任及教师，实现班级与学生的基础管理，并提供人员结构数据可视化分析，提升学校管理效率。

## 2. 功能介绍

### 模块一：注册登录模块
- 用户注册与登录认证
- JWT验证

### 模块二：员工管理模块
- 教师/班主任的增删改查
- 职位设置（普通教师/班主任/年级主任/学校领导）
- 任教班级分配
- 新增员工删除员工

### 模块三：班级模块
- 班级信息的增删改查
- 新增班级，删除班级

### 模块四：学生模块
- 学生信息的增删改查
- 入班/调班/退班操作
- 学生基本信息维护（姓名、性别、学号、联系方式等）
- 新增学生删除学生

### 模块五：数据可视化模块
- 学生性别比例统计（饼图展示）
- 教师职位分布统计（饼图/柱状图展示）

## 3. 技术栈
- 前端：Vue 3 + Element Plus + ECharts
- 后端：Spring Boot
- 数据库：MySQL
